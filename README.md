# Simple Image Viewer

WebPを含む一般的な画像フォーマットを、シンプルなUIで閲覧・操作することを目的とした画像ビューア

---

## コンセプト

Windowsで画像を素早く閲覧するための、軽量でシンプルな画像ビューアを目指す

特にWebP画像でも簡単に回転・拡大縮小などの操作ができる、シンプルなビューワを実現する

基本機能は画像閲覧に絞りつつ、将来的に機能を追加しやすい構成で開発する

---

## Supported Platforms

- Windows 10
- Windows 11

---

## 対応フォーマット

以下のような一般的な画像フォーマットへの対応を予定している

- JPEG (`.jpg`, `.jpeg`)
- PNG (`.png`)
- WebP (`.webp`)
- BMP (`.bmp`)
- GIF (`.gif`)

---

## 機能

- 画像の表示
- ウィンドウサイズに合わせた画像表示
- 90度単位での画像回転
- 画像の拡大・縮小
- 同一ディレクトリ内の画像を前後に移動
- キーボードショートカット
- マウス操作
- 最小限の操作ボタン
- ショートカットキーのカスタマイズ
- フルスクリーン表示
- Windows実行ファイル (`.exe`) としての配布
- Windowsの既定画像ビューアとしての利用

---

## 基本操作

初期設定では、一般的な画像ビューアに近い操作を予定している

| Key | Action |
| --- | --- |
| `←` | Previous image |
| `→` | Next image |
| `R` | Rotate 90° clockwise |
| `Shift + R` | Rotate 90° counter-clockwise |
| `+` | Zoom in |
| `-` | Zoom out |
| `0` | Fit to window |
| `1` | Actual size (100%) |
| `F11` | Fullscreen |

キー割り当ては、将来的に設定画面または設定ファイルから変更できるようにする予定

---

## 設計方針

### ファイル変更はしない

初期バージョンでは、画像に対する回転や拡大縮小などの操作は表示上のみ行い、元の画像ファイルは変更しない

将来的に、回転状態を画像ファイルへ保存する機能の追加を検討する

### 必要最低限の UI

画像の閲覧を邪魔しないよう、UIは可能な限りシンプルにする

操作はキーボード・マウスを中心としつつ、基本的な操作にはUI上のボタンも用意する

### 拡張性

画像表示処理とUI・ショートカットなどを可能な限り分離し、将来的に機能を追加しやすい構成とする
